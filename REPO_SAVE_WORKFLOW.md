After every meaningful workflow update, save the related files into this repo and push them to GitHub.

- Agent files

- Verification JSON files

## Security Rule

Never commit credentials, passwords, application passwords, API keys, access tokens, cookies, or session files.

Use environment variables for live publishing credentials, and redact sensitive values from chat logs before saving.
